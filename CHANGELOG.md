# Changelog

## `v1.0.0-showcase` — 2026-08-16

First complete public research-engineering case study for Parlons LSQ Runtime v1.5.

### Included

- model-first README explaining the idea, hand-built ML pipeline and research direction;
- frozen 29-class recognition contract and exact model identity;
- final Frontend and Backend/reference provenance;
- Android, Web and Windows local-inference architecture;
- future-ready server/hybrid inference seam documented without activating a recognition HTTP route;
- six curated visual evidence assets across Android, Web, Windows and Arabic RTL;
- qualitative prototype observations and known robustness sensitivities presented without inflated accuracy claims;
- privacy notes for camera redaction and external-reference testing;
- clear public-Showcase/private-source access boundary;
- build manifest and machine-readable release manifest;
- release validator with screenshot hash verification;
- roadmap from the frozen first-generation baseline toward larger, more varied LSQ research.

Runtime v1.5 is now preserved as the project's first reproducible research-to-product checkpoint.
